# TerraFusion Branding & Media Assets

This directory contains all official TerraFusion branding, media, and web splash assets.

## Structure
- `/web_splash/` — Cinematic splash page (HTML, CSS, assets, README)
- `/media/` — Audio/video bumpers (MP4, WAV, Lottie, README)
- `/assets/` — Logos, SVGs, favicons, and supporting graphics
- `README.md` — This file

## Usage
- Use `/web_splash/` for the standalone or React-integrated splash experience
- Use `/media/` for presentations, onboarding, or video intros
- All assets are optimized for both web and offline use

## Customization
- Swap out video, logo, or color palette as needed for county or campaign-specific deployments
- See each subdirectory's README for integration and deployment instructions
